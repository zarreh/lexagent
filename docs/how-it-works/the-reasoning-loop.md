# The reasoning loop

1. **Understand** the question and the jurisdictions involved.
2. **Retrieve** relevant statute sections from both the TX and CA corpora.
3. **Retrieve** relevant synthetic precedent summaries.
4. **Reason** and draft an answer with inline citations.
5. **Verify** that every cited statute section or case actually exists in the
   retrieved corpus.
6. **Return** the answer, or refuse / request clarification if verification
   fails or the question is out of scope.
